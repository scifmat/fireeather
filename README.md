# 守护火羽·千舰之夜

B站 Vtuber 直播间房管模拟网页小游戏。穿越回 **2022年10月12日** 火羽ひのめ的生日会直播间，担任她的房管——在弹幕上到主播弹幕机之前的 **2 秒内**，点掉黑粉弹幕，守护这一晚。

> 你无法改变历史，但至少在这一晚，替她挡下每一条黑粉弹幕。
> ——四年后的 10 月 12 日，3600 人登上了她的舰。

## 玩法简介

- 右侧面板弹幕出现后 **2 秒内可点击**，随后同步到直播画面内的弹幕机（主播侧），不可再操作。
- **点击负面弹幕**（黑粉）＝已办，好感度 **+3**（连击 ≥5 时 +4）。
- **漏掉负面弹幕**＝漏办，好感度 **−8**，且会以红色气泡上到主播弹幕机。
- **误伤正常弹幕**（含陷阱弹幕）＝误伤，好感度 **−5**。
- 好感度初始 50，**归零立即判负**；撑过 **100 条弹幕**即通关，按好感度结算 SSS~D 评级。

单局约 4.5~5 分钟，难度分三阶段递进（负面占比 15% → 28% → 35%）。

## 快速开始

无服务端、无构建、零第三方依赖：

1. 下载或克隆本仓库；
2. **双击根目录 `index.html`** 即可游玩（支持 Chrome / Edge / Firefox 及移动端浏览器）。

> 项目使用 `file://` 协议直接运行，无需 `npm install`、无需启动本地服务器。若浏览器支持受限，也可用任意静态服务器托管根目录。

## 自定义内容

所有可玩内容均为纯数据文件，直接编辑 `public/data/` 下对应 `.js` 即可，**增删即生效、无需改代码**：

| 想改什么 | 编辑文件 |
| --- | --- |
| 好感度数值、弹幕节奏、阶段占比、评级档位 | `public/data/config.js` |
| 通关/失败副标题文案、通关彩蛋 | `public/data/comments.js` |
| 新增应援/普通/陷阱弹幕 | `public/data/danmaku-positive.js` |
| 新增黑粉弹幕 | `public/data/danmaku-negative.js` |
| 观众昵称与身份属性 | `public/data/audience.js` |

> 注：等级、舰长、灯牌等观众属性本期仅随数据下发、不在界面渲染，留作后续升级。

## 技术说明

- **零依赖纯静态**：HTML/CSS/JS 分离，未引入任何第三方库与构建工具。
- **file:// 兼容**：因浏览器在 `file://` 下拦截 `fetch()` 与 ES Module，本地数据统一采用 `.js` 包裹 JSON（结构与 JSON 完全一致，便于后续迁移），脚本以普通 `<script defer>` 按序加载。
- **全局命名空间**：所有脚本挂载于单一全局 `HMG` 命名空间。
- **进度存储**：教程已读标记写入 `localStorage`（键 `hinome_mod_seen_v1`，带异常兜底），清除浏览器数据可重新查看教程。
- **响应式**：PC 双栏（直播屏 + 弹幕面板），移动端单栏自适应。
